# 💘 VibeMatcher — знакомства по вайбу

**VibeMatcher** — это веб-приложение на Flask, которое помогает людям находить друг друга по общим интересам, внешним данным и активности. Пользователи могут создавать подробные анкеты, искать подходящих людей с помощью гибких фильтров и безопасно общаться только после взаимного согласия.

Проект выполнен и демонстрирует полный стек технологий: ORM, авторизацию, загрузку файлов, REST API, адаптивную вёрстку и деплой на хостинг.

## ✨ Основные возможности

- 🔐 **Регистрация и авторизация** (Flask-Login, хеширование паролей)
- 🧑‍🎨 **Редактирование профиля** (имя, возраст, город, интересы, контакты, аватар)
- 🔍 **Умный поиск** с фильтрами:
  - пол, возраст (от/до)
  - город, цвет волос, национальность
  - **поиск по интересам** (ключевые слова — «вайб»)
  - только онлайн
- 💌 **Механика откликов**: отправить заявку → получить согласие → видеть контакты
- 🚫 **Чёрный список**: блокировка нежелательных пользователей, разблокировка
- 🟢 **Онлайн-статус**: автоматическое отслеживание активности
- 🛡️ **Текстовая модерация**: фильтр запрещённых слов в описании
- 🧠 **ИИ-заглушка** для проверки фото (Google Vision API можно подключить)
- 🎨 **Адаптивный дизайн** (Bootstrap 5 + собственные стили)
- ⚡ **Production-ready** запуск через Waitress

## 🚀 Быстрый старт (локально)

### 1. Клонирование репозитория
```bash
git clone https://github.com/yourusername/vibematcher.git
cd vibematcher
2. Создание виртуального окружения и установка зависимостей
bash
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

pip install -r requirements.txt
3. Создание тестовых данных 
bash
python seed.py
Будут созданы два пользователя: alice / bob с паролем 123.

4. Запуск приложения
Для разработки (с отладкой):

bash
python run.py
Сервер стартует на http://127.0.0.1:5000.

Для production (быстрее, многопоточный):

bash
pip install waitress   # если ещё не установлен
python wsgi.py
Сервер стартует на http://127.0.0.1:8080.
📖 Как пользоваться
Регистрируетесь или входите под тестовыми данными (alice / 123).

Заполняете профиль: имя, возраст, город, интересы, фото.

Ищете людей через фильтры — по интересам, городу, полу, онлайну.

Отправляете заявку, нажав «Откликнуться» на карточке.

Когда другой человек принимает заявку, вам обоим становятся видны контакты (телефон, email).

Неприятных пользователей можно заблокировать через чёрный список.
